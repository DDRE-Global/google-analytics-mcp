  • Real app adoption: 101 unique users in 28 days (58 in the last 7 days, 212 in 90 days) — consistent with the actual user base. 46 of them are first-time users of the property in this window.
  • Usage is growing: active users +31.8% WoW (44 → 58) and sessions +29.7% (185 → 240). Sep 21–25 was the strongest stretch (19–28 users/day).
  • /login is the top page (92 of 101 users, 392 views ≈ 4.3 views/user) — repeated logins/token re-entry. If this is expected SSO token-link behaviour it's fine, but it's the first place to look if auth feels flaky.

  • Apple-first, mobile matters: Apple desktop + mobile = 66% of users; 28 of 101 users (28%) use mobile — non-trivial for a back-office app. Windows is a small minority (10 users).
  • Traffic attribution is tool-driven: "Unassigned" (434 sessions — deep links/SPA) and Referral (175 — SSO redirects, e.g. monday.com) dominate over Direct. No organic/paid acquisition; 40 new users came Direct.
  • Data-quality note: unfiltered property totals (~35.8k users) are dev/E2E noise; the public /moneypenny page adds ~195 one-view visitors. Both must be filtered out (per prompts/weekly-leadership-report.md: never report unfiltered activeUsers).
