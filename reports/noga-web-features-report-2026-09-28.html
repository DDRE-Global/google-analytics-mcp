6 · Search → Offer → Viewing pipeline no prod usage in window

The core broker loop: /search (requirements + Brief Hub) → /offer → /viewing, plus /lead. 28 days, production.

  • No production page views on any of these routes in the window — the pipeline is currently dev/E2E-only (heavy localhost presence: /search, /lead, /listing-e2e-*, requirement-e2e-*).
  • If these features are intended for prod users, this is the biggest product signal in the report: the transactional core of the product has no live usage yet. If they're not released, hide them from prod navigation to avoid confusion.
  • Gap: none of these routes have conversion events (requirement created, offer made, viewing booked). A pipeline funnel report is impossible until events exist.
